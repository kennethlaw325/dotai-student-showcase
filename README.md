# Dot.ai AI Builder — Student Showcase

A public directory of 25 first-cohort student demonstration sites, with screenshots and direct links.

The gallery preserves the September 11, 2026 UTF-8-corrected edition. The 25 destination URLs returned HTTP 200 when checked on October 6, 2026. This check does not certify all JavaScript interactions.

The linked showcase repositories are separate public demonstration copies. They use demonstration data; some use mocked backends or historical snapshots. They are not presented as production services. Original student repositories were not modified by this directory deployment. Author/project attribution is retained on each card and in the linked showcase repositories.

`index.html` contains the complete gallery and embedded screenshots. GitHub Pages serves the repository root. No package installation or build step is required.
